# 板块扩展页面维护规则

主页只保留摘要和入口。能改变板块定价逻辑的公司，在本目录建立独立 HTML 页面。

## 页面固定结构

### 研究分析：这家公司好不好

1. 这家公司在做什么：白话解释客户、产品、收费、壁垒与本季变化。
2. 财报数字快照。
3. 核心矛盾与增长路径。
4. 管理层说法和外部反证。
5. 板块传导：直接受益、竞争、二阶受益、情绪高 Beta。
6. 公司质量结论。

### 交易决策：什么证据该做什么

固定顺序：

1. 证伪清单
2. 价格结构
3. 事件日历
4. 期权定价
5. 情境树
6. 反方检核

所有动作必须写成 if-then。价格和期权数据没有刷新时，明确写“待补”，不能沿用旧值假装实时。

## 四级信息标签

- `硬`：SEC、公司 IR、正式财报、正式披露。
- `管`：管理层说法，尚待验证。
- `三`：第三方数据、同行财报、渠道调查。
- `市`：价格、成交量、缺口、估值、期权结构。

## 下季度 Loop

页面底部必须保留本季预测表。下季度更新时：

1. 逐条标记“验证 / 部分验证 / 证伪”。
2. 写出实际结果和判断偏差原因。
3. 调整公司质量与交易决策。
4. 再建立下一季度的新证伪清单。

禁止直接删除错误预测；错误本身是研究流程最有价值的数据。

共享文件：`report.css`、`report.js`。新增页面优先复制现有 APP 或 PLTR 页面，保持手机端和标签交互一致。
