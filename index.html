财报助手

先回答这家公司好不好，再把交易动作绑定到证据、价格和时间；新观点与后续验证会持续补进对应记录。

仅比较已录入结构化口径的公司；缺少可靠可比数据的旧记录排在后面。

当前市场叙事与主线

综合财报、业绩会、X、采访和视频提炼。叙事强度不是看多/看空，而是衡量“这条主线是否被多家公司、多个数据点和市场价格共同验证”。

强度口径：9分以上 = 多家公司财报和价格同时确认；8分以上 = 有强证据但还需后续季度交叉验证；7分左右 = 正在形成但证据仍偏单点；低于7分 = 仅作为观察线索。

并购跟踪

跟踪报价、价差、谈判阶段、融资与监管风险，以及下一次会改变成交概率的事件。市场价格为记录更新时快照，不是实时行情。

评分框架

财报质量   = 本季度收入、利润、现金流和指引相对预期的兑现度
股价反应   = 财报后价格如何消化预期差，以及反应能否持续
持续性质量 = 护城河、订单可见度、客户结构、现金转化与未来几个季度的可重复性
总分       = 财报质量 + 股价反应 + 持续性质量
叙事强度   = 独立的10分制主线指标，不直接与个股总分相加
  • 以后打分更吝啬：90分以上只给“业绩、指引、叙事、股价反馈、跨公司验证”同时成立的报告。
  • 单季 beat 不等于高分；如果只是市场预期太低、或一次性因素贡献，分数必须打折。
  • SanDisk 上一季只作为“财报质量”benchmark，不再作为综合 benchmark；综合 benchmark 更接近 ANET/SHOP 这种业绩、叙事、后续验证都能闭环的案例。
  • 高 beta 个股如果只是在跟随主题交易，不能和核心龙头用同一套分数标准。
  • 每份新财报都要回看上一季判断：哪些验证了，哪些失效，哪些需要降权。

目标不是把新闻改写成中文，而是建立一个能反复校验的“市场叙事数据库”。

总分解释

分数含义要求
90+稀缺强确认业绩、指引、管理层发言、股价反馈、产业链 read-through 同时站住。
80-89优秀但仍需验证核心指标强，但估值、单点证据或后续价格反馈仍有扣分项。
70-79方向积极财报不差，叙事有苗头，但还没有形成强主线。
60-69普通/分歧headline 可以，但质量、持续性或市场接受度不足。
60以下风险优先核心指标或叙事被财报削弱，需要优先防守。

权重

维度权重说明
财报质量40只看当季兑现：收入、EPS、利润率、FCF、订单、backlog和指引相对预期。
股价反应35盘后/次日及后续价格、成交、卖方预期修正、估值约束与“利好兑现”。
持续性质量25判断好数字能否重复：护城河、客户集中度、订单可见度、资本强度、现金转化与周期性。

叙事强度标准

强度判断标准
9分以上至少两家核心公司财报验证，且股价/估值/订单或客户预算同时确认。
8-8.9分证据很强，但仍集中在少数公司、少数数据点或单一季度。
7-7.9分方向正在形成，需要下一季财报或更多公司交叉验证。
7分以下作为观察线索，不进入核心主线。

扣分项

  • 财报好但股价连续走弱，综合分要下调，不能只看业绩本身。
  • P/S>50x 或 Forward PE>200x 的股票，必须证明成长还在加速，普通 beat and raise 不够。
  • 靠 capex、价格周期或短期订单拉动的公司，要特别检查持续性。
  • 上一季预测落空的主题，下一次必须降权，直到重新被数据验证。
